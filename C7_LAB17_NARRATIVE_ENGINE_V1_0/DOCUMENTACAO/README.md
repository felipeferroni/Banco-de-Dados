# C7 LAB17 — Narrative Engine v1.0

Execute `EXECUTAR_LAB17.bat` ou `py LAB17\EXECUTAR_TUDO.py`.

O motor descobre narrativas latentes de forma determinística. Os nomes são IDs neutros (`NARRATIVA_001` etc.); descritores emergem dos genes, famílias e associação histórica. Nenhuma narrativa é sinal operacional.
